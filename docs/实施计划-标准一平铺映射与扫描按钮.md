## 1. 背景与目标

### 1.1 现状
- `check_integrity`（`src-tauri/src/commands.rs:264`）已能识别三套头像包标准，`SetupCard.svelte` 已三态展示，
  前端 `api.checkIntegrity`、`types.ts:IntegrityResult` 就绪。
- **替换流程只支持标准二**：`FaceMapper::new`（`src-tauri/src/face_mapper.rs:43`）仅索引一级子目录、按 14
  种族名（`correct_ethnic`）抽图；标准一（图片直铺、无子目录）→ 池为空 → 无映射。

- 名单预览表 `PlayersTable` 只在挂载/翻页/搜索时 `load()`，数据来自 `rtf_cache`——**只有执行过 Replace 才有数据**。

### 1.2 目标
1. **标准一替换**：判为标准一时，把包根全部图片作为**单一头像池**，对名单每个 UID **完全随机**抽图，
   **忽略 RTF 国籍/种族码**；支持 Preserve/Overwrite/Generate 三种模式；预览与单人微调同样可用。
2. **标准二不回归**：14 目录的匹配抽图逻辑**逐行保持不变**，并有显式回归测试。
3. **标准三预留并拦截**：本次不实现 65 目录映射，检测到即**明确报错/提示**，架构上留出单一扩展位。
4. **识别逻辑单一来源**：三套标准的"判定"只在 `facepack.rs` 一处实现；`face_mapper` 不再自行做集合比较、
   不依赖 FACEPACK 常量。
5. **新增两个按钮**（SetupCard「当前任务」卡）：
   - 「扫描头像」= 扫描头像包并**缓存图片索引**（供替换复用），结果**写日志**。
   - 「扫描RTF」= 解析当前 RTF 并**填充名单预览**（无需先 Replace），结果**写日志**。
   - 「选择文件」按钮文案改为「选择RTF」。

### 1.3 已确认的关键决策
- 平铺映射写入 `config.xml` 用 `from="图片名"`（**无目录前缀**，`MappingEntry.ethnicity = ""`）。
- **保留** `validate_image_dirs` 命令 / `api.validateImageDirs` / 其 `lib.rs` 注册（不删；仅 `ReplacePanel` 改调 `check_integrity`）。
- 标准三：后端 `replace_flow` 返回失败、前端 `ReplacePanel` 早提示，双重拦截。
- 扫描结果统一写入日志（`logger.info("scan", …)` → `log:batch` 事件 → LogDrawer 实时显示）。
- 「扫描头像」默认与替换流程共享缓存（按 `img_dir` 命中即复用，避免重复扫盘）。

## 2. 总体设计

新增底层模块 **`src-tauri/src/facepack.rs`** 作为"标准识别"的唯一来源，被 `commands.rs`、`face_mapper.rs`、
`replace_flow.rs` 共用（`facepack` 不反向依赖它们）。它提供：

1. 两个标准常量：`FACEPACK_DIRS`（14）、`FACEPACK_DIRS_65`（65）——从 `commands.rs` 迁入。
2. 布局枚举 `PackLayout` + **纯分类函数** `classify(subdirs, has_root_images)`（唯一判定入口）。
3. **重扫描器** `scan_pack(img_dir) -> PackScan`：一次 `read_dir` 同时建 `faces_map`（子目录→图名集合）与
   `root_images`（根图名集合），并调用 `classify` 得出 `layout`。`PackScan` 即替换/扫描缓存的载体。

两种扫描深度、一套判定逻辑：
- **轻扫描**（`check_integrity` 用）：只列子目录名 + 探测根是否有图 → 喂给 `classify`；**不读子目录内文件**（保持现状开销）。
- **重扫描**（`scan_pack`，替换/扫描头像用）：建完整图片索引 → 内部同样调用 `classify`。
- 两处扫描喂给 `classify` 的子目录集合都先剔除**垃圾目录**（`facepack::is_junk_dir`：`.` 开头 / `__MACOSX`，
  常见于 macOS 压缩的社区包，否则平铺包会被误判 `Unknown`、映射全空）；只过滤判定输入，`faces_map` 不动。

`FaceMapper` 不再自己分类：`FaceMapper::new(img_dir)` = `from_scan(img_dir, scan_pack(img_dir)?)`，直接拿 `layout`。

```rust
//! 头像包"标准识别"的唯一来源：标准常量 + 布局分类 + 目录扫描。
use std::collections::{BTreeMap, BTreeSet};
use std::path::Path;

/// 14 个种族目录（标准二）。保持历史拼写（含 Seasian）。
pub const FACEPACK_DIRS: [&str; 14] = [
    "African", "Asian", "Caucasian", "Central European", "EECA", "Italmed",
    "MENA", "MESA", "SAMed", "Scandinavian", "Seasian", "South American",
    "SpanMed", "YugoGreek",
];

/// 65 个细分种族目录（标准三）。保持社区原始拼写（含 Finstonia / Staff / WF）。
pub const FACEPACK_DIRS_65: [&str; 65] = [
    "Afroamerican", "Afrocaribbean", "Albania", "AlbanianGreek", "Anglosphere",
    "ArabGulf", "Armenian", "Azerbaijan", "Baltics", "BrazilMixed",
    "CaucasianNA", "Caucasus", "CentralAfrica", "CentralAsian", "CentralEurope",
    "China", "Denmark", "EastAfrica", "EastBalkan", "EastSlavic",
    "Filipino", "Finstonia", "France", "HornOfAfrica", "Hungary",
    "Iceland", "IndigenousSA", "Indonesia", "Iran", "Ireland",
    "Israel", "Italia", "Japan", "Korea", "Maghreb",
    "MainlandSEA", "Malaysia", "Mashriq", "Mestizo", "MixedRace",
    "Mongolia", "Netherlands", "NorthernSA", "Norway", "PacificIslanders",
    "Poland", "Portugal", "Romania", "SahelianAfrica", "Scandinavian",
    "Singapore", "SouthAsia", "SouthConeSA", "SouthernAfrica", "Spain",
    "Staff", "Sweden", "Tajikistan", "Turkish", "Uzbekistan",
    "Vietnam", "WF", "WestAfrica", "WestBalkan", "WestSlavic",
];

/// 头像包布局（三套标准 + 兜底）。
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PackLayout {
    Flat,                          // 标准一：无子目录 + 根目录有图片
    Empty,                         // 无子目录且无图片（空包）
    Standard2 { complete: bool },  // 子目录集合 ⊆ 14 组；complete=恰等于
    Standard3 { complete: bool },  // 子目录集合 ⊆ 65 组；complete=恰等于
    Unknown,                       // 含未知名或跨两套混用
}

impl PackLayout {
    /// 映射为对外的"标准号"：1/2/3；0=无法识别。
    pub fn standard(&self) -> u8 {
        match self {
            PackLayout::Flat | PackLayout::Empty => 1,
            PackLayout::Standard2 { .. } => 2,
            PackLayout::Standard3 { .. } => 3,
            PackLayout::Unknown => 0,
        }
    }
    pub fn is_flat(&self) -> bool { matches!(self, PackLayout::Flat) }
}

/// 唯一的标准判定入口（纯函数，不读盘）。
pub fn classify(subdirs: &BTreeSet<String>, has_root_images: bool) -> PackLayout {
    if subdirs.is_empty() {
        return if has_root_images { PackLayout::Flat } else { PackLayout::Empty };
    }
    let s14: BTreeSet<&str> = FACEPACK_DIRS.iter().copied().collect();
    let s65: BTreeSet<&str> = FACEPACK_DIRS_65.iter().copied().collect();
    let names: BTreeSet<&str> = subdirs.iter().map(String::as_str).collect();
    if names == s14 { return PackLayout::Standard2 { complete: true }; }
    if names == s65 { return PackLayout::Standard3 { complete: true }; }
    // 仅 Scandinavian 一名重合；同时 ⊆ 两套时先命中标准二（历史主格式）。
    if names.is_subset(&s14) { return PackLayout::Standard2 { complete: false }; }
    if names.is_subset(&s65) { return PackLayout::Standard3 { complete: false }; }
    PackLayout::Unknown
}

/// 一次目录扫描的产物：子目录图片索引 + 根图片索引 + 布局。
#[derive(Debug, Clone)]
pub struct PackScan {
    pub faces_map: BTreeMap<String, BTreeSet<String>>, // 子目录名 → 图片名（去扩展名）
    pub root_images: BTreeSet<String>,                 // 根目录图片名（去扩展名）
    pub layout: PackLayout,
}

fn is_image_ext(name: &str) -> bool {
    matches!(name.rsplit('.').next().map(|s| s.to_ascii_lowercase()).as_deref(),
             Some("png") | Some("jpg") | Some("jpeg"))
}

/// 打包/系统垃圾目录：macOS 压缩包解出的 `__MACOSX`、各类 `.` 开头目录（.git 等）。
/// 仅用于过滤 classify 的输入；faces_map 仍原样收录，标准二 generic 路径行为不受影响。
pub fn is_junk_dir(name: &str) -> bool { name.starts_with('.') || name == "__MACOSX" }

/// 重扫描：建 faces_map + root_images，并调用 classify 得出 layout。
pub fn scan_pack(img_dir: &str) -> Result<PackScan, String> {
    let root = Path::new(img_dir);
    let mut faces_map = BTreeMap::new();
    let mut root_images = BTreeSet::new();
    for entry in std::fs::read_dir(root).map_err(|e| format!("读取头像包目录失败: {e}"))? {
        let entry = entry.map_err(|e| e.to_string())?;
        let path = entry.path();
        let fname = entry.file_name().to_string_lossy().to_string();
        if path.is_dir() {
            let mut imgs = BTreeSet::new();
            if let Ok(files) = std::fs::read_dir(&path) {
                for f in files.flatten() {
                    if f.path().is_file() {
                        let n = f.file_name().to_string_lossy().to_string();
                        let stem = n.split('.').next().unwrap_or("").to_string();
                        if !stem.is_empty() { imgs.insert(stem); }
                    }
                }
            }
            faces_map.insert(fname, imgs);
        } else if is_image_ext(&fname) && !fname.starts_with('.') {
            // 根图词干用 file_stem（与 parse_image_path_in_pack 同规则，"a.1.png"→"a.1"）；
            // 跳过 . 开头文件（macOS AppleDouble 的 ._x.png 会以 "._x" 入池、污染 resolve）。
            let stem = Path::new(&fname).file_stem()
                .map(|s| s.to_string_lossy().to_string()).unwrap_or_default();
            if !stem.is_empty() { root_images.insert(stem); }
        }
    }
    // classify 输入剔除垃圾目录（如 __MACOSX），否则 Mac 打包的平铺包会被判 Unknown。
    let classify_input: BTreeSet<String> =
        faces_map.keys().filter(|n| !is_junk_dir(n)).cloned().collect();
    let layout = classify(&classify_input, !root_images.is_empty());
    Ok(PackScan { faces_map, root_images, layout })
}
```
> 词干规则（重要）：`faces_map` 用 `split('.').next()`（与旧 `FaceMapper::new` 逐字节一致，标准二零回归）；
> `root_images` 用 `file_stem` 且跳过 `.` 开头文件——与 Step 2.5 `parse_image_path_in_pack` 同规则，
> 平铺链路（池 → `write_xml` → `resolve_image_file`、单人换脸）对 `a.1.png` 这类点号文件名全程自洽。

**同时**：`src-tauri/src/lib.rs` 顶部模块声明处（现有 `mod commands;` 等附近）加 `mod facepack;`；
`src-tauri/src/commands.rs` 顶部把原常量定义改为 `pub use crate::facepack::{FACEPACK_DIRS, FACEPACK_DIRS_65};`
（详见 Step 5.1、Step 6.1）。

   /// 词干用 file_stem，与 facepack::scan_pack 的 root_images 同规则（"a.1.png" → "a.1"）。
   pub fn parse_image_path_in_pack(img_dir: &str, image_path: &str) -> Option<(String, String)> {
       let p = Path::new(image_path);
       let ext = p.extension()?.to_str()?.to_ascii_lowercase();
       if !matches!(ext.as_str(), "png" | "jpg" | "jpeg") { return None; }

       else { Some((parent.file_name()?.to_string_lossy().to_string(), image)) }

   pub fn check_integrity(img_dir: String) -> IntegrityResult {
       let mut subdirs = std::collections::BTreeSet::new();
       let mut has_images = false;
    if let Ok(rd) = std::fs::read_dir(&img_dir) {
        for e in rd.flatten() {
            let p = e.path();
            let fname = e.file_name().to_string_lossy().to_string();
            if p.is_dir() {
                if !facepack::is_junk_dir(&fname) { subdirs.insert(fname); } // 跳过 __MACOSX 等
            }
            else if !fname.starts_with('.')   // 跳过 ._x.png 等隐藏文件，与 scan_pack 口径一致
                && p.extension().and_then(|x| x.to_str())
                .map(|x| matches!(x.to_ascii_lowercase().as_str(), "png"|"jpg"|"jpeg")).unwrap_or(false) {
                has_images = true;
            }
        }
    }
       let layout = facepack::classify(&subdirs, has_images);
       let standard = layout.standard();
       let status = match layout {
           PackLayout::Flat => "complete",
           PackLayout::Empty | PackLayout::Unknown => "unknown",
           PackLayout::Standard2 { complete: true } | PackLayout::Standard3 { complete: true } => "complete",
           PackLayout::Standard2 { .. } | PackLayout::Standard3 { .. } => "fixable",
       };
       let missing: Vec<String> = match layout {
           PackLayout::Standard2 { complete: false } =>
               FACEPACK_DIRS.iter().filter(|d| !subdirs.contains(**d)).map(|d| d.to_string()).collect(),
           PackLayout::Standard3 { complete: false } =>
               FACEPACK_DIRS_65.iter().filter(|d| !subdirs.contains(**d)).map(|d| d.to_string()).collect(),
           _ => Vec::new(),
       };
       let expected_total = match standard { 2 => 14, 3 => 65, _ => 0 };
       let found = if standard == 1 { 0 } else { subdirs.len() };
       IntegrityResult { standard, status: status.into(), missing, found, expected_total }
   }

       match standard { 1 => "标准一/图片直铺", 2 => "标准二/14 目录", 3 => "标准三/65 目录", _ => "无法识别" }

   fn scan_images_core(img_dir: &str) -> Result<(usize, u8, PackScan), String> {
       let scan = facepack::scan_pack(img_dir)?;
       let total = if scan.layout.is_flat() { scan.root_images.len() }
                   else { scan.faces_map.values().map(|s| s.len()).sum() };
       Ok((total, scan.layout.standard(), scan))
   }
   fn scan_rtf_core(rtf_path: &str) -> Result<(RtfScanResult, Vec<PlayerRecord>), String> {
       let mut parser = RtfParser::new();
       if !parser.check_rtf_valid(Path::new(rtf_path))? { return Err("RTF 文件格式无效".into()); }
       let data = parser.parse_rtf(Path::new(rtf_path), false, &NAT_TRANSLATION)?;
       let summary = RtfScanResult {
           total: data.len(),
           newgan: data.iter().filter(|p| p.uid.starts_with(NEWGAN_UID_PREFIX)).count(),
           detailed: data.iter().any(|p| p.detailed.is_some()),
           language: parser.rtf_language.clone(),
       };
       Ok((summary, data))
   }

   #[tauri::command]
   pub fn scan_images(state: State<'_, AppState>) -> Result<ImageScanResult, String> {
       let img_dir = { state.pm.lock().unwrap().cur_group.clone().ok_or("请先选择头像包目录")? };
       let (total, standard, scan) = scan_images_core(&img_dir)?;
       *state.faces_cache.lock().unwrap() = Some(FaceIndex { img_dir, scan });
       state.logger.info("scan", format!("扫描头像完成：{total} 张图片（{}）", layout_label(standard)));
       Ok(ImageScanResult { total, standard })
   }

   #[tauri::command]
   pub fn scan_rtf(state: State<'_, AppState>) -> Result<RtfScanResult, String> {
       let rtf = { state.pm.lock().unwrap().get_cur_rtf() };

       *state.rtf_cache.lock().unwrap() = data;
       state.logger.info("scan", format!("扫描 RTF 完成：{} 条（随机人 {}，{}，{}）",
           summary.total, summary.newgan, if summary.detailed {"详细名单"} else {"基础名单"}, summary.language));
       Ok(summary)
   }

## 7. 边界与本次不做
- **不实现标准三映射**（仅拦截）。未来落点：`facepack::classify` 的 `Standard3` 分支保持不变，另在 `FaceMapper`
  增加针对 65 目录的选图（需引入 65 名与"国籍/种族码 → 65 目录"的映射表），并移除 Step 4 的拦截与 Step 12 的 `standard===3` 早拦。
- **空目录**（无子目录无图片）：`check_integrity` 记 `standard1/unknown`（不算完整）；替换因无池自然产出空映射（沿用现状）。
- **平铺图片名唯一性**：以"去扩展名后"为准（同名不同扩展会被 `BTreeSet` 去重）；平铺链路统一用 `file_stem`
  （`root_images` 与 `parse_image_path_in_pack`），标准二 `faces_map` 维持 `split('.').next()` 口径不变。
- **垃圾目录**：`__MACOSX` 与 `.` 开头目录不参与布局判定（`facepack::is_junk_dir`，仅过滤 classify 输入），
  `faces_map` 原样收录；根目录 `.` 开头的图片文件（如 AppleDouble `._x.png`）不入池、单人换脸也拒收。
- **缓存时效**：`faces_cache` 仅按 `img_dir` 命中；扫描后若改动磁盘图片，需重新点「扫描头像」再替换。
- **同步命令**：`scan_images`/`scan_rtf`/`check_integrity` 均为同步命令（与既有 `validate_image_dirs`/`read_image` 一致）；
  超大包/超大名单可能有短暂 UI 阻塞，如需可后续改 `async`。
