# 2026-09-17

## 追加结论：faces_map vs recursive_pools 的"取代"问题（承接 09-16 的词干口径讨论）

- `image_stem` 是函数（文件名 → 词干），`faces_map` / `recursive_pools` 是索引，"函数取代索引"不成立。
  能谈取代的是 `legacy_face_stem` 这条规则，或 `faces_map` 这个索引本身。
- **关键事实：对「按 FolderList 白名单过滤后」的消费方（标准二池、标准三主池），
  `faces_map` 与 `recursive_pools` 唯一的实质差异就是词干口径**——键集（白名单目录名）、
  收录范围（都只收该目录的直接图片，孙目录都不收）、空目录建键、垃圾目录差异都被白名单挡掉了
  （14/62 个名字里不可能出现 `__MACOSX` 或 `a/b`）。多级键/根键只影响标准二
  `image_pool_dirs` 的"③全部池目录"兜底分支。
- 因此「删掉 faces_map 全改用 recursive_pools」对标准二的净效果 ≈ 直接改 `legacy_face_stem`，
  但更没好处：多删了 classify 那个「只要键名」的用途（`templates/mod.rs:214` 只读 keys），
  还多带上根键/多级键的行为变化。**推荐仍是只换标准三主池的来源。**
- 唯一能拿来说的收益：现在每个一级目录被 `read_dir` 两次（faces_map 一趟 + walk_recursive 一趟），
  删掉 faces_map 能省一遍遍历——太小，不值得为此扩大影响面。
- `image_stem` 的注释（`facepack_scanner.rs:112`）自称"图片词干的唯一口径"，`faces_map` 是唯一背离它
  的地方；长期若要收敛，方向是统一到 `image_stem`，但要么接受标准二输出变化（路线 A），
  要么只做标准三局部（路线 B）。

## 已实施：统一词干口径（路线 A，用户拍板「a.1.png → a.1，尽量复用」）

- `facepack_scanner.rs`：**删掉 `legacy_face_stem`**（取首个 `.` 之前，`"a.1.png"`→`"a"`）。
  `scan_pack_progress` 的第二趟不再单独 `read_dir` 建 faces_map，而是
  `let imgs = recursive_pools.get(fname).cloned().unwrap_or_default(); faces_map.insert(fname, imgs);`
  —— **faces_map 与 recursive_pools 同源同键**，词干由 `image_stem`（`walk_recursive` 内）统一产出，
  顺带省掉每个一级目录的第二遍遍历。垃圾目录不入递归池 → faces_map 收录空集键（判定层按
  `is_junk_dir` 过滤键名，行为不变）。
- 副作用（有意的行为变更）：faces_map 不再收非图片文件（`notes.txt`/`config.xml` 以前的
  `split` 规则会把 `notes`/`config` 塞进池、写出定位不到的 from），隐藏文件由
  `is_extension && !starts_with('.')` 过滤（否则 `image_stem("._a.png")` = `"._a"` 会入池）。
  含点号文件名的标准二包 from 由 `"SpanMed/a"`（定位不到）变成 `"SpanMed/a.1"`（能定位）。
- 标准三的主池与兜底池因此从结构上同键，`drop_image` / `exclude_used` 的"双索引漂移"整类问题消失；
  `Standard3Rule::drop_image` 的注释改成"两份都摘是为了不依赖上游同源这一前提"。
- 新增测试 4 个：`facepack_scanner::faces_map_and_recursive_pools_share_stem_rule`（同源同键）、
  `standard3::dotted_filename_has_single_identity_in_both_indexes`（禁重复两次抽 → 第二次 None；
  Preserve 剔除同理）、`face_mapper::preserve_with_no_duplicates_excludes_images_occupied_by_xml`
  （旧空缺的 Preserve+禁重复 e2e，确定性：SpanMed 被占 e0/e1 → 新球员必得 e2）、
  `face_mapper::standard2_dotted_filename_stem_resolves_to_real_file`。
  全量 127 passed / 0 failed（`templates::tests::real_pack_smoke_scan_classify_pick` 仍 ignored）。
- 文档：`docs/抽图模型设计-标准二.md` §4 补了「词干口径唯一」一条。
