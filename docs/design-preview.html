设计理念：教练席控制台（The Dugout）

让 NewGAN Manager 看起来像 FM 的延伸，而不是一个通用蓝白 SaaS：玩家刚从深色皮肤的 FM 里切出来，视觉上无缝衔接。本页记录调研依据与设计取向；设计方案页给出令牌与组件规范，实施路径页给出分批落地计划。

FM26 皮肤调研六条共性四条原则已确认决策

1FM26 热门皮肤调研

按 FMScout / sortitoutsi / FMSkinBuilder 的浏览与下载量梳理 2026 赛季头部皮肤（调研时间：2026-09）：

Material Skin 26
50 万+ 浏览深浅皆可高信息密度

多年沿用的 Material 配色，重排世界杯面板、球员大脸 Profile、按钮统一样式。

CTRL 26 · MW90
31 万+ 浏览cleandarkminimal

官方自我标签即「干净 / 深色 / 极简」：弱化单选组、次级按钮加回细边框、表格斑马纹、移除紫渐变、状态色统一色相。

Darkside v5
深蓝declutter动态瓷砖

明确主张「现代化、去杂乱、降低眼疲劳」，为单档数百小时的玩家设计；重排所有 Overview 页。

MNB · AnSeOs
Muted Navy Blue低分辨率翡翠备选

柔和海军蓝配色，Portal 只放最重要的管理元素；另出翡翠绿主题包。

TSO · DaveHouto
dark-blue比赛日重设

深蓝主题 + 可滚动瓷砖与快速切换按钮，强调清晰度、可用性与沉浸感。

AlexMorak / Kojuro
去紫低眼疲劳

卖点即「去掉 FM26 烦人的紫蓝调」；Kojuro 仅换色不动结构，降低视觉刺激。

另有 SAS26、skogr（La Liga 风直播图形、热图）、TinyHips OLED 纯黑等，方向一致。

2跨皮肤的六条共性

  1. 深海军蓝是绝对主流：Darkside / MNB / TSO / CTRL 全部 dark-navy，目标是长时间使用不刺眼。
  2. 集体「去紫」：FM26 默认紫蓝被普遍替换为克制的海军蓝 + 单一强调色。
  3. 降噪（Declutter）第一：弱化装饰、弱化单选组、统一状态色阶、表格加斑马纹、按钮加细边框。
  4. 瓷砖（Tile）与背景层级取代粗边框卡片；导航靠激活区块高亮，而非图标堆砌。
  5. 字体偏小偏紧、信息密度高：几乎所有皮肤都换字体，数据强调等宽对齐。
  6. 球员档案页是视觉重心：大脸肖像、多边形切角（Lotsgon polygon）成为标志性语言。
★

本工具恰好是一个「头像工具」——FM 皮肤里最标志性的多边形/圆角人像母题，与「给随机人长脸」的业务高度呼应，应作为品牌符号反复出现。

3四条设计原则

原则 01

面孔是主角

圆角人像用于品牌区、单人微调、空状态；处处强化「批量匹配头像」的产品心智，而不是文件处理器。

原则 02

降噪如 CTRL

去掉满屏 1px 方框，改用背景深浅分层 + 间距分组；全界面只有三层深度：base / surface / raised。

原则 03

状态一眼可读

就绪 / 进行中 / 警告 / 错误用统一色阶，且图标 + 文字双通道表达，不单纯依赖颜色（照顾色觉障碍）。

原则 04

密集但有节奏

13px 基准字、等宽数字、表格高信息密度；区块之间保留呼吸留白，长列表（30 万行级）不产生视觉噪声。

4已确认的关键决策（2026-09-10）

主题方向
双主题都做深色「教练席海军蓝」为默认；浅色「日间球场」由同一套令牌映射，侧栏底部一键切换并记忆。
强调色
青绿 Teal #2DD4A7（深色）/ #0DA880（浅色）取自应用图标柴犬的项圈色；在海军蓝上对比强烈，且不与语义红绿混淆。
旅程引导
顶部五步 Stepper选档与头像包 → 校验与名单 → 选模式 → 执行替换 → 查看与微调；随状态自动点亮，纯引导、不可点，不改业务流程。
头像造型
圆角矩形（12px）品牌图、单人微调大头像、空状态占位统一；与面板圆角语言一致。

具体设计方案

令牌（Design Tokens）是唯一样式入口：所有颜色、圆角、字体、动效都通过 CSS 变量消费，深色/浅色只差一组令牌取值，未来主题演进只改 :root 与 [data-theme] 两段。

2字体与排版

字体族（零新增依赖）

  • 界面："Segoe UI Variable","Segoe UI","Microsoft YaHei UI",system-ui——Win10/11 自带，不打包字体，安装包不增大。
  • 等宽："Cascadia Code",Consolas——路径 / UID / 日志 / JSON 编辑器。
  • 全局 font-variant-numeric: tabular-nums：进度、百分比、行数、UID 等宽对齐不跳动。

3视觉母题

母题 A

面板竖条标题

3px 青绿竖条 + 标题，替代旧版光秃秃的加粗文字；深/浅主题下层级都清晰。

母题 B

状态胶囊 Pill

圆角 99px、语义软底 + 同色文字 + 圆点；图标与文字双通道，不只靠颜色。

母题 C

圆角人像

12px 圆角矩形：品牌 38px、微调大头像 168px、空状态同尺寸虚线占位。

母题 D

激活条

侧栏当前组 / 当前导航：3px 左侧青绿条 + 软底，源自 FM 皮肤的 active-section。

母题 E

凹槽输入

只读路径框使用 inset 深色底 + 等宽字 + 类型图标，长路径尾部对齐。

母题 F

无渐变装饰

不使用渐变文字、玻璃拟态、发光；仅进度条允许青绿单向渐变。

5界面注解（对照「界面预览」页）

主工作台（12 个落点）

  1. 品牌区：圆角柴犬 + 字标 + v2.0 描边胶囊。
  2. 五步 Stepper：完成✓ / 当前双环 / 待办灰，随状态点亮，不可点。
  3. 面板标题：竖条 + 标题 + 当前档/组小字。
  4. 路径行：凹槽等宽框 + 文件夹/文件/齿轮图标 + 等宽幽灵按钮列。
  5. 完整性状态条：齐全绿 / 缺失琥珀+一键创建 / 未知灰，语义胶囊。
  6. 模式：三段连体控件，选中段软底，说明常驻右侧。
  7. 选项：纯 CSS 自绘 toggle（底层仍是 input checkbox）。
  8. 主 CTA：青绿全宽 + 播放图标；禁用中性灰。
  9. 进度：8px 条 + 等宽百分比 + 后端状态原文。
  10. 侧栏当前组：左激活条 + 软底；RTF 圆点；× 悬停显红。
  11. 名单表格：斑马纹、粘顶表头、排序箭头、分页胶囊。
  12. 状态栏：状态胶囊（就绪绿点 / 忙碌琥珀呼吸点）+ 日志红色错误角标。

其余三个界面

单人微调 → 球员卡：168px 圆角头像为视觉中心；姓名大字 + UID 等宽胶囊；国籍/种族等元信息胶囊；资料字段从「只读输入框表单」改为 4 列「标签—值」信息格；替换行沉底。字段再多也不像表单。

日志抽屉：560px 右抽屉、180ms 滑入；级别 chip + 「仅该级别」；WARN 琥珀 / ERROR 红 / CRITICAL 反白红条；虚拟列表（virtua）与字段结构不变。

规则模态：标准二/三分段切换；raised 表面 + 投影；等宽 JSON 凹槽编辑器，焦点环青绿；保存校验逻辑不动。

i

原生 ask() / message() 系统弹窗保持不动（无法皮肤化）；如二期需要统一，可做应用内确认弹窗组件。

6无障碍、对比度与动效

无障碍

  • 正文 / 控件文字对比度 ≥ 4.5:1（双主题逐一核验）。
  • 所有可交互元素有可见焦点环：3px --focus 半透明环。
  • 开关、分段控件底层保持原生 input/button，键盘 Tab 与读屏语义不变。
  • 状态一律「图标/形状 + 文字」双通道，不单独依赖色相。
  • 抽屉遮罩支持 Esc / 点击关闭并带 aria-label。

动效预算（硬约束）

  • 所有动画时长 ≤ 200ms（抽屉/模态 180ms，悬停 140–160ms）。
  • 位移 ≤ 8px（抽屉 8px、模态 8px 上浮）。
  • 进度条宽度过渡 150ms；忙碌呼吸点 1.3s 透明度循环。
  • 全局适配 prefers-reduced-motion: reduce：关闭动画与过渡。

改造与实施路径

视觉完全重排，业务零改动。分 5 批（B0–B4）顺序推进，每批结束都可运行、可回退；主要工作量 = 令牌 + class + 少量纯展示标记。

硬约束B0–B4 批次文件对照质量门范围边界

0实施硬约束（不可突破）

  • 不新增任何依赖：纯 CSS + Svelte scoped，不引 tailwind / 组件库。
  • 不动业务流程、Rust、IPC 协议、stores 数据逻辑。
  • 用户可见文案沿用 src-svelte/lib/text.ts，仅新增必要的主题/Stepper 词条。
  • 所有危险操作的 ask() 确认框逻辑与措辞不变。
  • 核心数据留 Rust 侧、IPC 只传分页/摘要的架构不变。
  • 保持三层架构 UI / services / core；一组件一文件、一模块一文件。
  • SVG 图标集中到 src-svelte/lib/icons.ts。
  • 所有视觉取值走设计令牌，便于二期暗色/主题演进。
  • 动效 ≤200ms、位移 ≤8px；适配 reduced-motion。
  • 首版不含侧栏折叠；深色为默认，浅色同期交付。
